## Upload

1. Download and unzip `Creative_Studio_GitHub_Ready.zip`.
2. In this repository, choose **Add file → Upload files** on `main`.
3. Drag the extracted **`manga`** and **`music`** folders onto the upload page. Preserve their relative paths.
4. Commit directly to `main`.
5. Check the manga image link in `README.md`.

The repository should remain private unless you deliberately decide to share the artwork. The source screenshot used for reference is excluded.
